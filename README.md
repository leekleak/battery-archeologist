## What is this?
This app was made as a local, on-device port of the abandoned Google project "Battery Historian". While the original project has been maintained by some forks, the core process of having to manually extract the battery data, run a docker container on your desktop and manually import the data is just way too obtuse and clunky when it can all be done locally with Shizuku.
